# Billionaire Mode

An offline-first Android personal operating system for focused execution:

- Daily Top 3 and promise streaks
- Goal deadline countdown
- Personal reminders, Daily Arsenal, and verified historical quotes
- Founder’s Playbook and strategy notes
- Business dashboard and weekly review

## Install

Download the APK from `releases/` and install it on an Android device running Android 8.0 or newer. Enable notifications and exact alarms when Android asks.

## Build

Open this project in Android Studio, install Android SDK Platform 35, and run the `assembleDebug` Gradle task. The app is built with native Android Java and stores all data locally on the device.

## Release

The release build is optimized, but publishing or distributing updates broadly requires an owner-managed Android signing key and a signed release APK/AAB.
